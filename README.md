# birding

Kurullo is a platform for birdwatchers to mark the birds they've seen on their field trips, along with their counts, to keep a comprehensive record of it. It also functions as a photo blogging and discussion platform, where birders can post the photographs they took, and also discuss ornithology related questions. Admins can moderate content and manage moderators and advertisers, and update the bird database.

Tech stack: 
- MERN stack
- React Native
