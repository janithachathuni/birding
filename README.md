# birding

Kurullo is a digital platform created for the birdwatching community, bringing together field trip documentation and social networking in one place. Built with the MERN stack and supported by a React Native mobile app, it works as both a tool for keeping scientific records and a space where bird enthusiasts can connect, share, and grow their passion for ornithology.


CORE FEATURES: BIRDER

- Field trip logging
Birders can update details of their field trips, along with checklists to mark how many birds they have spotted. Can also include special notes if they wish.
- Photo blogging
Users can share high-quality bird photography
- Comminuty discussion
A dedicated space for ornithology discussions, species identification help, and knowledge sharing among birders of all experience levels
- Comprehensive and educational bird database
Maintained and updated by administrators to ensure accurate species information and taxonomy


CORE FEATURES: ADMIN

- Content moderation
- User and moderator management
- Advertiser management for platform sustainability
- Bird database maintenance and updates


TECH STACK 

- Database: MongoDB
- Backend: Express.js, Node.js
- Frontend: React (Web application), React Native (Mobile application)
